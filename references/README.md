# Chrome Web Store top-200 reference set

Design-study corpus of 200 well-rated, widely installed Chrome extensions: name, users,
rating, category, store URL, and store-hosted image URLs (not copied). Selection and
limits are in `chrome-webstore-top200.json` (`selection`, `caveats`). Not a global
ranking: candidates came from 20 category listings.

Use: open the store URLs to study popup, options, side-panel and listing design, then
distil patterns into a NouGenDesign spec. Do not re-host store images.
