4 · Verify

Gate of record: headless reference renderer (tools/visual_verify.py) — never this webview.

The shell's webview render is advisory (OS webviews differ per platform). A variant is locked against the package and judged by the reference gate, so webview variance can never change what passes. Verify therefore runs headlessly, not from a button in the shell:

python3 tools/visual_verify.py --package designs/nougenai-brand \
  --html <surface.html> --out <findings-dir> \
  --screenshot-cmd "weasyprint {html} {png}"
